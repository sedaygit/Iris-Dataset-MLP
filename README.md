# Iris_Dataset_MLP
(EN) A Multi-Layer Perceptron (MLP) deep learning model built with TensorFlow/Keras for classification on the Iris dataset.  
(TR) Iris veri seti kullanılarak TensorFlow/Keras ile geliştirilmiş Çok Katmanlı Algılayıcı (MLP) ve derin öğrenme sınıflandırma modeli.

Bu projede, klasik Iris veri seti üzerinde çiçek türü sınıflandırması yapmak amacıyla TensorFlow ve Keras kütüphaneleri kullanılarak bir Çok Katmanlı Algılayıcı (MLP - Multi-Layer Perceptron) yapay sinir ağı modeli tasarlanmış ve eğitilmiştir. 
Kullanılan Teknolojiler: Python, Scikit-Learn (Veri önişleme ve standartlaştırma), TensorFlow/Keras (Model mimarisi ve eğitimi), Matplotlib (Başarım ve kayıp grafikleri).
